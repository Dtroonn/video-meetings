Снизу дан скилл на русском языке, это скилл, который должен из наших PRD файлов (уже есть skill prd) создавать фазы реализации. Создай на основе данного примера скилла снизу skill с названием plan. Plan должен сохраняться в /docs/plans. 
При создании скилла используй skill с названием create skill. Skill должен вызываться только по команде /plan.
```
---
name: plan
description: Разбивая PRD на фазы реализации. Использую, когда есть готовый PRD и нужно составить план разработки с независимыми фазами.
---

# Plan Generator

Прочитай PRD из файла: $ARGUMENTS

Создай план реализации и сохрани в файле `docs/plans/$ARGUMENTS.md` (используй перевод на английский и kebab-case)

## Структура плана:

# Plan: {название фичи}

**PRD:** $ARGUMENTS
**Дата:** {текущая дата}

## Фазы реализации

### Фаза 1: {название}
**Цель:** Что даёт эта фаза
**Затрагивает:** backend / frontend / database
**Задачи:**

- [ ] Задача 1
- [ ] Задача 2

**Когда готова:** Конкретный критерий

### Фаза 2: {название}

## Правила разбивки на фазы:
Каждая фаза должна давать рабочий результат.
Фазы независимы, можно остановиться после любой.
Первая фаза как минимальный рабочий путь (Tracer Bullet)
Не больше пяти задач в одной фазе
Backend и frontend одной фичи разной фазы.

## Правила
Читай PRD внимательно, план должен покрывать все критерии готовности.
Не добавляй задачи, которых нет в PRD.
Если PRD не полный, задай вопрос перед созданием плана.
```
